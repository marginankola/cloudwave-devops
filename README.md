
# Cloudwave — FiveM DevOps Infrastructure Project

Cloudwave is a self-hosted FiveM Enhanced free-roam server deployed on AWS.

This project demonstrates practical DevOps skills through infrastructure
automation, configuration management, CI/CD, monitoring, and backup
and recovery workflows.

## Project Objectives

- Deploy and manage a FiveM server on AWS.
- Provision infrastructure using Terraform.
- Automate server configuration using Ansible.
- Implement CI/CD using GitHub Actions.
- Monitor infrastructure and services using Prometheus and Grafana.
- Implement backup and recovery procedures.
- Document deployment, troubleshooting, and cleanup.

## Technology Stack

| Category | Technology |
|---|---|
| Cloud | AWS |
| Operating System | Ubuntu Linux |
| Infrastructure as Code | Terraform |
| Configuration Management | Ansible |
| CI/CD | GitHub Actions |
| Version Control | Git and GitHub |
| Monitoring | Prometheus and Grafana |
| Game Server | FiveM Enhanced |
| Administration | txAdmin and vMenu Enhanced |
